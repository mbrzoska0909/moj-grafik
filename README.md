# Mój Grafik Manual v1.2

Zmiany względem v1.1:
- od 2. dnia miesiąca dostępny jest przycisk `↓ Kopiuj powyżej`,
- kopiuje cały wpis z poprzedniego dnia: zmianę, oznaczenie/brygadę lub wpis specjalny,
- np. `3/IX` skopiowane z dnia 4 na dzień 5 pozostaje `3/IX`,
- jeśli poprzedni dzień nie ma wpisu, przycisk niczego nie zmienia.

Zachowane są reguły M1, M2, M1*, M2* i pozostałe reguły v1.1.
