# Mój Grafik FINAL v2.0

Ręczne wprowadzanie grafiku bez OCR.

## Grupy kalendarzy
- 1 zmiana: 06:00–14:00 — obejmuje także BHP i BO.
- 2 zmiana: 14:00–22:00.
- 3 zmiana: 22:00–06:00 następnego dnia.
- Wolne/UW: osobny kalendarz całodniowy.

## Oznaczenia M
- M1 i M2 są dodatkowymi oznaczeniami. Mogą wystąpić ze zmianą 1, 2 lub 3 i zachowują standardowe godziny tej zmiany.
- M1* i M2*: zmiana 1 = 05:00–13:00, zmiana 2 = 13:00–21:00, brak zmiany 3.
- Grupa kalendarza zawsze wynika z numeru zmiany, więc np. 1/M2* trafia do kalendarza 1 zmiany, a 2/M2* do kalendarza 2 zmiany.
