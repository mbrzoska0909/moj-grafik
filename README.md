# Mój Grafik Manual v1.1

Dodano oznaczenia:
- M1
- M2
- M1*
- M2*

Reguły:
- M1 i M2 nie zmieniają standardowych godzin: 1 = 06:00–14:00, 2 = 14:00–22:00, 3 = 22:00–06:00.
- M1* i M2*: 1 = 05:00–13:00, 2 = 13:00–21:00; zmiana 3 jest niedozwolona i nie jest eksportowana.
- Pozostałe reguły aplikacji pozostają bez zmian.
